Documentación de investigación detrás de la biblioteca de ejercicios de ATLETIX.

## Principios

1. **No se inventa nada**: toda afirmación tiene una fuente y una clasificación de evidencia.
2. **Las fuentes se guardan en la base de datos**: cada ejercicio referencia sus estudios o guías.
3. **Esquema aditivo**: agregamos campos y tablas nuevas, nunca eliminamos ni cambiamos los existentes.
4. **El entrenador decide**: la biblioteca informa, no reemplaza el criterio profesional.
