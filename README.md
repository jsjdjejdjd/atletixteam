# ATLETIX 🏋️

Plataforma de entrenamiento y asesoramiento de calistenia.

**DONDE LOS FUERTES SE CREAN**

## Estructura

- `apps/web` → Aplicación web (Next.js + TypeScript + Tailwind). Web pública + paneles privados.
- `apps/mobile` → Aplicación móvil (Expo / React Native) para Android e iOS.
- `packages/shared` → Código compartido (tipos, validaciones, constantes).
- `supabase` → Configuración de la base de datos (SQL versionado).

## Requisitos

- Node.js LTS
- Git
- Cuenta de Supabase
